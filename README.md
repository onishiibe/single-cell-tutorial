# single-cell-tutorial
A beginner-friendly single-cell RNA-seq tutorial using the developing zebrafish heart dataset GSE296176.
This repository contains the materials accompanying the The Node Writing Challenge video tutorial on getting started with single-cell RNA-seq analysis.
Using the developing zebrafish heart dataset GSE296176, the tutorial introduces a simple workflow for exploring single-cell data with R and Seurat.

Tutorial steps:
1. Get the data — Find and download a public dataset from GEO.
2. Prepare the data — Load the data into R, create a Seurat object, and perform basic quality control.
3. Visualize the cells — Explore cell populations using UMAP.
4. Ask a question — Explore the expression of cardiac developmental genes and identify differentially expressed genes.
